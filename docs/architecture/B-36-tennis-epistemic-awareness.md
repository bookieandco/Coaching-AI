# B-36 — Tennis Epistemic Awareness

## Purpose

B-36 introduces an explicit self-awareness layer for coaching analysis. The system must distinguish what it observed from what it inferred, what it is hypothesizing, what it simulated, and what it simply does not know.

## Labels

- `OBSERVED` — directly supported by an evidence item.
- `INFERRED` — interpretation derived from observations.
- `HYPOTHESIS` — a testable explanation, not an established fact.
- `SIMULATED` — generated by a scenario/simulation engine.
- `UNKNOWN` — required information is unavailable.

## Core invariant

```text
MISSING EVIDENCE ≠ NEGATIVE EVIDENCE
UNKNOWN ≠ INFERRED
SIMULATED ≠ OBSERVED
HYPOTHESIS ≠ FACT
```

The layer must never manufacture evidence to close an information gap.

## Integration

```text
EVENT / VIDEO / TRACKING
        ↓
OBSERVED EVIDENCE
        ↓
PLAYER + MATCHUP INTELLIGENCE
        ↓
INFERENCES / HYPOTHESES
        ↓
SCENARIO ENGINE
        ↓
SIMULATED RESULTS
        ↓
EPISTEMIC ASSESSMENT
        ↓
COACH COMMAND CENTER
```

## Borrowed design ideas

The SelfAware reference motivates explicit unknown/uncertain handling rather than forcing an answer when evidence is insufficient. The Levels of Self MCP reference motivates exposing structured scenario/exercise resources through a tool boundary rather than embedding every interaction in free-form model output.

Neither reference becomes a source of coaching facts or canonical match state.

## Safety boundary

B-36 does not diagnose athletes, infer psychological disorders, or make coaching decisions. It is an epistemic bookkeeping and presentation layer.
